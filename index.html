What it does

Your buddy walks in, waves, and walks away

Hydration Buddy lives quietly in your system tray. When it is time for water, one of five animated characters walks in from the edge of your screen, waves, and shows a friendly message. Click I drank it, snooze, or dismiss, and they walk away again.

Features

Everything you need to stay hydrated

🚶‍♀️

Walking avatars

Five hand-drawn characters with smooth walk, turn, wave and idle animations.

📊

Hydration dashboard

A 7-day chart of your glasses per day, today's total, weekly total and daily average.

⏰

Flexible schedule

Remind every 1 to 480 minutes, with one-click presets from 15 minutes to 2 hours.

🌙

Quiet hours

No reminders during the hours you choose, or while your PC is locked.

💬

Your own messages

30 built-in messages plus any you write yourself, with {name} for your name.

🎭

Pick your buddy

A surprise each time, take turns in order, or always the same character.

😴

Snooze and pause

Snooze a reminder for a few minutes or pause everything for an hour from the tray.

🚀

Starts with Windows

Launches silently in the tray and begins reminding straight away.

🔒

Private

Everything stays on your PC. No account, no internet connection, no tracking.

Using it

Simple by design

Tray icon, left click
Open settings and the dashboard.
Tray icon, right click
Remind me now, log a glass, pause for an hour, turn reminders on or off, quit.
Reminder bubble
I drank it adds a glass to today's count, Snooze brings your buddy back later, ✕ dismisses.
Dashboard
The Reset button sets today's count back to zero. Earlier days are kept.

For developers

Build from source

Requires Node.js 18 or newer on Windows.

git clone https://github.com/Sabariks092/hyderation-buddy.git
cd hyderation-buddy
npm install

npm start          # run the app in development
npm run dist       # regenerate the artwork and build the installer into dist/
CommandWhat it does
npm startRuns the app with Electron
npm run generateRenders every sprite sheet and icon, then packs the sprites
npm run spritesOnly re-packs the existing sprite sheets into animated AVIF
npm run check:spritesCompares the packed sprites with their PNG sources
npm run distBuilds dist/Hydration Buddy Setup <version>.exe

Project layout

src/
  main.js          main process: scheduling, tray, windows
  store.js         settings and drinking history
                   (JSON in the user's app-data folder)
  sprites.js       unpacks the animated AVIF sprites
  overlay/         the transparent window the avatar walks in
  bubble/          the clickable message bubble
  settings/        settings window and dashboard
  assets/generated generated artwork
scripts/
  generate-assets.js   renders the characters and animations
  to-avif.js           packs sprite sheets into animated AVIF

How the installer stays small

The animations are 273 frames per character. Stored as PNG sprite sheets they take 62 MB. Packed as animated AVIF, where each frame is compressed against the one before it, they take about 5 MB, and the app unpacks them back into sprite sheets in a fraction of a second when a reminder starts.
